## Key Findings

### 1. M1.8 Stress Tests Now Pass

The M1.8 stress tests (`test_rapid_sequential_queries`, `test_mixed_context_sizes`) that previously failed intermittently now pass reliably when run as part of the full test suite.

**Reason:** Natural warmup from prior tests in the suite reduces GC pauses and cache misses.

### 2. GPU Architecture Gap

RTX 5060 (SM_120/Blackwell) is the newest NVIDIA architecture but PyTorch 2.x only supports up to SM_90 (Hopper). This affects GPU testing but not CPU benchmarks.

**Workaround:** Graceful skip with clear message.

### 3. Coverage Stable at 92%

Coverage remained stable between M1.8 (92.96%) and M1.9 (92.13%). The small decrease is due to adding new fixture code that isn't directly tested.
