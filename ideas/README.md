---

## Idea Lifecycle

```
💡 BRAINSTORM → 🔬 EXPLORING → 📋 PROPOSED → 🚀 PROMOTED → ✅ IMPLEMENTED
                     ↓              ↓
                 🗃️ ARCHIVED    ❌ REJECTED
```

| Status | Meaning |
|--------|---------|
| 💡 BRAINSTORM | Initial idea, not yet explored |
| 🔬 EXPLORING | Actively investigating feasibility |
| 📋 PROPOSED | Ready for milestone consideration |
| 🚀 PROMOTED | Converted to official milestone |
| ✅ IMPLEMENTED | Now part of the codebase |
| 🗃️ ARCHIVED | Interesting but not pursuing |
| ❌ REJECTED | Not feasible or valuable |

## Promotion Criteria

An idea can be promoted to a milestone when:

1. **Feasibility** - Implementation path is clear
2. **Value** - Measurable improvement identified
3. **Integration** - Fits existing architecture
4. **Resources** - Time estimate reasonable (< 1 week)
5. **Novelty** - Publication potential assessed
